# Map data attribution

The bundled country-boundary geometry in `js/data/world-countries.js` is derived from the 1:110m Natural Earth Admin 0 country dataset, redistributed by **geojson-atlas**.

- Source repository: https://github.com/BenPortner/geojson-atlas
- Source dataset: https://github.com/BenPortner/geojson-atlas/tree/main/geojson/natural_earth/world/110m
- License: Creative Commons Zero 1.0 Universal (CC0 1.0)
- Dataset scale: 1:110m; boundaries are generalized and are not intended for legal or cadastral use.
- The geometry was simplified for browser Canvas rendering and bundled locally so the game works offline.

Natural Earth boundary definitions are cartographic representations. They do not express a political position on disputed borders or sovereignty.
